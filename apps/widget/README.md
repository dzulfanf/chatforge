# Chatforge Widget

> Status: **not yet implemented.**

Embeddable chat widget built with Vue 3 and TypeScript and shipped as a framework-agnostic **Web Component** (custom element), so any website can embed it with a script tag.

Its job:

- Chat launcher and conversation UI
- STOMP/WebSocket client connection to the backend
- Isolated styling (Shadow DOM)

Configuration: see [`.env.example`](./.env.example).
